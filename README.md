# 📱 AxionOS Changelog  

## 📅 Latest Version - **1.3-BETA**  
**Security Patch:** April 2025

### 🚀 What's New  
- **UI Enhancements**: Minor improvements and fixes to the user interface.
- **Bug Fixes**: Resolved various reported bug issues.
- **Launcher Improvements**: 
   - Added misc features and fixes over previous version.
   - Added option for global search when tapping hotseat/all apps search bar when "Pixel Search" is installed.
- **Performance Optimizations**:
  - Reduced aggressive CPU utilization caused by aggressive Uclamp and PELT multiplier tunings.
  - Improved performance mode tunings.
- **Camera Fixes**: Attempt to address an issue where the double power press camera gesture doesn't work.
- **System Optimizations**:
  - Reduced system latency for smoother performance.
  - Improved scheduling for system processes for better performance and efficient power usage.
- **GameSpace**: 
  - Added GameSpace bypass charging.
  - Games are now automatically added to gamespace after installation and set to performance mode.
- **New Features**:
  - Added per-app sensor blocking.
